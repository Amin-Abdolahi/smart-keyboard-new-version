\# Smart Keyboard v2



تشخیص و تبدیل خودکار layout فارسی/انگلیسی در لحظه تایپ.



\## ویژگی‌ها



\- تشخیص خودکار اشتباه layout

\- حباب شناور شبیه Grammarly

\- دیکشنری چندلایه و قابل توسعه

\- یادگیری از کاربر

\- پشتیبانی از چند زبان (فارسی، انگلیسی، آلمانی و...)

\- حالت دو زبانه بدون تغییر layout



\## نصب



pip install -r requirements.txt

python main.py
