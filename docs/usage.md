# راهنمای استفاده

## شروع کار

۱. برنامه رو اجرا کن.
۲. آیکون آبی کنار ساعت ویندوز ظاهر می‌شه.
۳. روی آیکون راست‌کلیک کن و شروع نظارت رو بزن.

## نحوه کار

برنامه در لحظه تایپ، layout رو تشخیص می‌ده. اگه layout اشتباه باشه:

- اطمینان بالا (بیشتر از ۰.۷۵): خودکار تبدیل می‌کنه.
- اطمینان متوسط (۰.۳۰ تا ۰.۷۵): پاپ‌آپ پیشنهاد نشون می‌ده.
- اطمینان پایین (کمتر از ۰.۳۰): هیچ کاری نمی‌کنه.

## مثال‌ها

مثال ۱: تبدیل خودکار

layout: EN
تایپ: sghl phgj ]x,vi
نتیجه: سلام حالت چطوره

مثال ۲: پاپ‌آپ پیشنهاد

layout: EN
تایپ: h,qhu vndti
پاپ‌آپ: اوضاع ردیفه

مثال ۳: یادگیری

layout: FA
تایپ: پشمام
برنامه: یاد می‌گیره پشمام یه کلمه معتبره

## کلیدهای میانبر

| کلید | عملکرد |
|---|---|
| Ctrl+Shift+F | تبدیل دستی متن تایپ‌شده |
| Escape | بستن پاپ‌آپ |

## تنظیمات

از منوی tray، گزینه تنظیمات:

### تب زبان‌ها

- زبان‌های فعال: انتخاب زبان‌هایی که می‌خوای پشتیبانی بشن.
- زبان اصلی: زبان پیش‌فرض.

### تب تبدیل

- آستانه تبدیل خودکار: بالاتر یعنی محتاط‌تر.
- آستانه پیشنهاد: پایین‌تر یعنی پیشنهاد بیشتر.
- زمان توقف: چقدر صبر کنه قبل از بررسی.
- تغییر خودکار layout: بعد از تبدیل، layout عوض بشه.

### تب رابط کاربری

- حباب شناور: نمایش یا عدم نمایش.
- صدای دینگ: پخش یا عدم پخش.
- زمان بسته شدن حباب: چند ثانیه بمونه.

### تب دیکشنری

- آمار دیکشنری.
- پاک کردن لاگ.

## نکات مهم

۱. دسترسی ادمین: برنامه نیاز به دسترسی ادمین داره برای hook کیبورد.
۲. آنتی‌ویروس: بعضی آنتی‌ویروس‌ها ممکنه گیر بدن.
۳. برنامه‌های محدود: توی بعضی برنامه‌ها مثل بازی‌ها کار نمی‌کنه.
۴. حریم خصوصی: همه چیز محلیه، هیچ داده‌ای ارسال نمی‌شه.

## سوالات متداول

### چرا برنامه توی بعضی برنامه‌ها کار نمی‌کنه؟

چون بعضی برنامه‌ها مثل بازی‌ها یا برنامه‌های run as admin اجازه تزریق کیبورد نمی‌دن.

### چطور دیکشنری رو گسترش بدم؟

فایل‌های smartkeyboard/data/*.txt رو ویرایش کن. یا از دکمه یاد بگیر توی پاپ‌آپ استفاده کن.

### چطور تنظیمات رو ریست کنم؟

فایل config.json رو از مسیر APPDATA پاک کن. برنامه دوباره می‌سازدش.

### چطور برنامه رو حذف کنم؟

فایل exe رو پاک کن. اگه می‌خوای داده‌ها رو هم پاک کنی، پوشه SmartKeyboard رو از APPDATA پاک کن.
